# PI-1ASIX
Este proyecto tiene como objetivo poder llevar a cabo lo aprendido en los diversos modulos de el primer año del grado superior para crear una simulacion de la infraestructura en red y sistemas de una empresa real.

## Objetivos
1. Apender a implementar servicios, configuraciones y sistemas en un entorno casi identico al que podria tener una empresa de verdad.
2. Decidir que configuraciones o sistemas deberan usarse en funcion de las circustancias.
3. Aprender a elaborar documentacion correctamente.

## Instalacion
Para llevar a cabo la instalación de lo necesario para comenzar con el proyecto, debemos disponer de al menos tres tarjetas de red en el servidor de comunicaciones.

## Comando
-Permitir IP forwarding en sysctl: `echo "net.ipv4.ip_forward = 1" | sudo tee /etc/sysctl.d/99-ipforward.conf`
